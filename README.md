# Descriptive-Statistics

Purpose of the Code


Data Preparation:

It creates a dataset containing the launch temperatures for 25 space shuttle missions.
Data Analysis:

It uses the pandas library to create a DataFrame from the dataset.
It calculates and prints descriptive statistics for the launch temperatures, providing insights into the distribution of the data (e.g., mean, standard deviation, min, max, quartiles).
Data Visualization:

It uses the matplotlib library to create a scatter plot of the launch temperatures against the mission numbers.
It adds a horizontal line at 29°F to highlight the temperature at which the Challenger shuttle was launched.
It labels the axes, adds a title, and includes a legend to make the plot informative and easy to understand.

Space Shuttle Launch Temperatures Analysis
This project analyzes the launch temperatures of 25 space shuttle missions and visualizes the data using a scatter plot. The analysis aims to provide insights into the temperature conditions during the launches and highlight the temperature at which the Challenger shuttle was launched.

Features
Data Preparation: Creates a dataset containing launch temperatures for 25 missions.
Data Analysis: Uses pandas to calculate descriptive statistics for the launch temperatures.
Data Visualization: Uses matplotlib to create a scatter plot of the launch temperatures, with a highlighted line for the Challenger launch temperature.
